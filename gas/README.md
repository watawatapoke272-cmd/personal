# 同期用 GAS のセットアップ

1. 新しい Google スプレッドシートを作る（名前は自由。手持ちデータの保存先になる）
2. 「拡張機能 → Apps Script」を開き、`Code.gs` の中身を `gas/Code.gs` で置き換えて保存
3. 「プロジェクトの設定 → スクリプト プロパティ」に `SYNC_KEY` を追加し、値に合言葉（自分だけが知る文字列）を入れる
4. 「デプロイ → 新しいデプロイ → 種類: ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**（合言葉で守る。Googleログインを要求する設定ではアプリから呼べない）
   - 初回は権限の承認が必要（スプレッドシートの読み書き）。「Googleによって確認されていません」と出るが、自分で作ったスクリプトなので次の手順で進める:
     「詳細」→「（プロジェクト名）（安全ではないページ）に移動」→「許可」
5. 表示された「ウェブアプリのURL（…/exec）」をコピー
6. アプリの「手持ち」タブ →「同期・バックアップ」に、URLと合言葉を入力して「保存して接続テスト」
   - PCとスマホそれぞれで同じ入力をする

## 動き

- 手持ちを変更すると数秒後に自動で同期。画面に戻ったときと起動時にも同期する
- シート `sv` / `swsh` に1匹1行、`party` にパーティの並びが保存される（スプレッドシートは手で編集しない）
- 食い違いは「個体ごとに更新時刻が新しい方」を採用（端末の時計がずれていると、古い方が勝つことがある）
- 削除も他の端末に伝わる（削除の記録が残る）

## コードを変えたとき

- デプロイを「新バージョン」で更新する（同じURLのまま反映される）
- 統合の規則は `src/merge.ts` と `gas/Code.gs` に同じものがある。片方を直したら両方直す

## 注意

- URLと合言葉を知っている人は、誰でも手持ちデータを読み書きできる。共有しない
- 合言葉はこの端末のブラウザ（localStorage）に保存される。共用の端末では「解除」する
